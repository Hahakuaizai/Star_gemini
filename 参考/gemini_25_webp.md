# Gemini 桌宠 25 个动作 WebP 图集制作规范与详细教程（6～10秒完整工程版）

> **文档适用对象**：本教程专为使用 **Gemini 图像生成 + Python (`Pillow` / `NumPy` / `SciPy`，无 OpenCV) 自动化管线** 制作高质量透明底 **WebP 精灵图集（Sprite Sheet）与动态 WebP** 打造，已与 `AI_ANIMATION_PIPELINE_GUIDE.md` 全量对齐。

> **核心规格与节奏标准**：单格画布严格锁定 **`384 × 384 px`**（48 帧 `8×6` = `3072 × 2304`，36 帧 `6×6` = `2304 × 2304`）；单个动作总时长严格控制在 **`6.0s ～ 10.0s`** 之间（48 帧精修舒展版推荐 **`8.0s ～ 9.0s`**），通过**精准光流/桥接补帧 + 变速节奏公式**做到发力干脆利落、过渡丝滑无重影、情绪卡点有呼吸感。

1. **生图构图锁与 `≥12%` 安全留白**：
   - 生图阶段角色占单格高度约 **`68%～72%`**，角色呆毛、猫耳、靴底、右侧猫尾、四肢指尖及所有道具粒子，距单格上下左右边缘必须保留 **`≥12%`** 纯黑安全留白，严禁触边或裁切。
2. **主体身高锁死与精准脚底锚点（严禁用整格 BBox 缩放）**：
   - 严禁使用含头顶粒子的整格 `getbbox()` 缩放（会导致冒特效时人物突然“缩水”）。
   - 在 `384 × 384` 画布下，仅测**角色主连通域**身高，纯站立/微动/原地转身动作锁死 **`TARGET_H = 304～308px`**（全片身高波动控制在 `±2～5px` 内），脚底锚定 **`GROUND_Y = 366`**，头中心水平对齐 **`x = 192`**。

   - **补靴防裁尾铁律**：若局部小腿微裁需借用 `anchor_stand` 补靴，必须在接缝 `seam_y` 以下做**全宽羽化拼接**，严禁只拼双腿列并把左右清零（否则会斩断右侧低垂猫尾）。
3. **“无→有→无”闭环与首尾锁死**：
   - 除 `睡觉三段式` 外，所有动作的**第 1 帧与最后 1 帧必须 100% 锁死为干净【标准正面站立】**（无道具、无眼镜、无粒子）。
4. **严禁半透明重影（No Alpha Cross-fade）**：
   - 绝对禁止使用帧间透明度叠化导致双影或黑影；补帧必须采用双向光流一致性门控或手绘过渡帧。

## 二、 省额度生图、三类补帧法与 6～10 秒配速公式

### 1. 省额度分段生图与锚点接力策略
- **单次生图铁律**：每次生图严格只尝试 1 次（Prompt 开头必须声明 `Make ONLY 1 generation attempt. Do NOT retry`），目视核查后再决定下一步。
- **2 段 `4×3`（24 关键帧）→ 48 帧丝滑动画（主力工作流）**：无需硬画 4 段，先以 `anchor_stand.png` 生第 1 段（12 格），运行 `python gemini\脚本\build_webp.py extract-anchors` 提取第 1 格与第 12 格作接力参考图，再生第 2 段（12 格），随后按动作类型选用下述三类方法补足至 48 帧。

### 2. 三类动作的“加中间帧”核心方法
1. **方法 A：常规肢体/表情/道具动作 → 双向金字塔光流 + 一致性门控插帧（纯 `NumPy + SciPy`）**
   - 直接复用 `gemini/脚本/expand_48.py` 中的 `pyramidal_optical_flow`（4 层高斯金字塔，`win_sigma=3.5, iters=6`）与预乘 Alpha `warp_rgba`。
   - **一致性门控**：前后向光流一致处平滑融合，遮挡/眨眼/粒子突变处果断吸附清晰帧，彻底杜绝双影；输出 Alpha 使用柔和抗锯齿曲线 `[28..228]`（严禁 `>=128` 硬二值化）。
   - **避坑铁律**：猫尾、扫帚或手臂发生**跨边大跳变**时，必须将该区间加入 `skip_cross` 跳过光流插帧，将帧额分配给同侧平滑过渡段；禁止对近似静止帧做 3 倍死板插帧制造“水帧”。
2. **方法 B：大角度转身 / 视角切换（如 `13tsundere`）→ 专用手绘过渡桥接图（Bridge Sheet）**
   - 用 `turn_start.png`（正面）和 `turn_end.png`（侧身）作双参考图，专门生成 1 张 `4×3` 桥接图补齐 `18° → 36° → 54° → 68°` 侧转与回正真实手绘帧，仅在少数同侧大跨度处单步光流补帧。
3. **方法 C：规则物理轨迹动作 → 程序化几何变换 + 次级惯性滞后**
   - **钟摆晃动（如 `14drag_float`）**：AI 只画**竖直悬挂**姿态 + 眨眼/踢脚；脚本先对竖直姿态光流补帧，再对眼部以下施加 **90° 相位滞后 S 曲线剪切波**（头部 100% 刚性不变形，发尾猫尾滞后飘动），最后绕支点 `(192, 30)` 旋转 48 个正弦角度 `θ_i = 15° · sin(2πi / 24)` 并程序化绘制双底色清晰的提拉线。
   - **跳跃动作（如 `10happy_jump`）**：不要把起跳帧脚底钉死地面，在腾空关键帧叠加平滑正弦抛物线抬升 `lift = max_lift * sin(πt)`（`max_lift ≈ 26～28px`），并校验头顶粒子不碰顶边。

### 3. 6～10 秒“利落不急促”变速配速公式
在合成动态 WebP 时，**禁止全片固定死板帧率**，48 帧精修动作总时长推荐落在 **`8.0s ～ 9.0s`**（全局允许区间 `6.0s ～ 10.0s`）：

| 动作阶段类型 | 单帧时长建议 (`ms`) | 视觉表现效果 |
| :--- | :--- | :--- |
| **爆发发力 / 敲击 / 挥扫 / 起跳下落 / 眨眼闭合** | `120ms ～ 145ms` | 干脆利落、有动感、不拖沓、不黏滞 |
| **常态推进 / 抬手 / 光流过渡 / 道具凝实与消散** | `160ms ～ 185ms` | 过渡舒展清晰，肉眼可轻松捕捉每个细节 |
| **表情卡点 / 思考停顿 / 庆祝定格 / 擦汗 / 首尾站姿** | `215ms ～ 250ms` | 给足情绪呼吸感与可读性，避免赶工感 |

## 三、 智能黑隙切分、抗锯齿去污与星云黑块剥离标准

### 1. 逐列智能黑隙切分（严禁 `w // 4, h // 3` 均分）
- 直接复用 `gemini/脚本/build_webp.py` 中的 `find_cell_boxes(sheet, cols=4, rows=3)`：先按整图列能量谷底切出 4 列，再在**每一列内部独立扫描行能量**，优先取紧贴上方角色靴底之下的**最上方零能量黑隙带**，既不切靴底又把下方角色头顶粒子完整留给下方格子。
- 若背景偏灰或第 3 行色块污染，先测顶部边框 95 分位亮度 `bg = np.percentile(arr[:12].max(2), 95)` 动态设阈值 `t = max(22, bg + 14)`；必要时仅裁取纯黑底前 2 行。

### 2. 零毛刺零黑边四步抠图与抗锯齿标准
1. **四边泛洪 + 绝对色度内部黑洞清理**：使用 `(max_rgb <= bg_thresh) & (chroma <= 14)` 清理外部黑底与腿间/尾弯封闭黑洞，绝不误伤角色深紫色衣裙。
2. **悬浮发光粒子反预乘（Un-premultiply）**：对独立于主体的星星、爱心、汗滴、音符等，按亮度 `scale = 255 / max_rgb` 还原纯亮色 RGB 并平滑赋透明；对白底可见度弱的纯白特效（受惊白线、提拉线）衬一层 `1～2px` 淡紫/深紫描边。
3. **外轮廓 `1～2px` 边界色彩去污**：找出外轮廓边界带 `boundary = dilate(fg, 1) & ~erode(fg, 2)`，将混入黑底的暗边缘像素 RGB 向角色标准深紫描边色 **`(68, 48, 98)`** 平滑收敛融合。
4. **边界 Alpha 高斯抗锯齿平滑**：仅在 `boundary` 上施加 `gaussian_filter(alpha, sigma=0.55 ~ 0.65)`，内部保持 `255` 实心、极低噪点 `< 10` 清零。**严禁 `alpha >= 128` 硬二值切边**！

### 3. 暖暗棕/黑紫色星云脏块腐蚀-生长剥离法
- 当星尘或发光弧线附带与主体粘连的暗色晕染时：
  1. 在 `384×384` 对齐后保护水手服衣裙（`x∈[148,236], y∈[172,282]`）与双靴（`x∈[150,234], y∈[312,366]`）核心区；
  2. 识别 `max_rgb < 118` 且 `R >= B - 4` 的暖暗棕星云带（角色冷紫描边均为 `B > R + 8`）；
  3. 对暗色候选区做 `erode(k=2)`——1~3px 细描边消失得以 100% 保护，厚重星云内核存活，再在非亮主体 1px 邻域内膨胀回填清零，并对剥离边缘反预乘提亮。

## 四、 25 个桌宠动作完整分镜、粒子描写与配速总表

> **符号说明**：标注 **👓** 的为**戴摘眼镜专属动作**（实装 4 个：03/05/18/19；20 号已按无眼镜精修版实装）；所有动作默认首尾为干净【标准正面站立】（睡觉三段式除外）。画幅统一 **`384 × 384 px`**。

### 模块 A：核心基础与工作状态类（6 个）

#### 01. 待机呼吸休闲（`01idle` | 8.5s | 48 帧 `8×6` | 循环）
- **动作分镜**：
  - `0.0s～2.5s`（帧 1～14）：标准正面站立，胸腔随呼吸自然微抬微落（幅度 `2~3px`），呆毛与右侧猫尾柔顺微晃；第 9～12 格完成一次**干脆利落的眨眼**（闭眼 2 格 → 迅速睁开 2 格）。
  - `2.5s～5.8s`（帧 15～34）：头部利落向左微转 `12°` 轻瞥四周，停留片刻后平滑转向右 `12°` 张望，长发发梢与猫尾保持恒定粗细随重心轻摆。
  - `5.8s～8.5s`（帧 35～48）：头部干脆回正，再完成一次轻快眨眼，呼吸平稳回落至第 1 帧无缝衔接。
- **粒子描写**：帧 6～42 在肩侧与发梢外围（避开脸部）轻柔浮现 `3～4` 颗离散的**暖金色与淡紫粉色小四芒星光点**，交替闪烁呼吸，首尾 4 帧淡出。
- **配速建议**：眨眼 `120ms`，呼吸与转头过渡 `175ms`，张望卡点 `220ms`。

#### 02. 打扫清理·利落站姿版（`02sweeping` | 8.8s | 48 帧 `8×6` | 循环）
- **动作分镜**（推荐 24 关键帧 + 24 帧防跨边光流补帧，参考 `02process_sweeping.py`）：
  - `0.0s～1.6s`（帧 1～8）：标准站立 → 右手虚握，木柄 Q 版魔法扫帚由紫金星光凝实成型，双手握柄、上身微前倾 `10°`，扫帚头稳落右前方地面。
  - `1.6s～4.4s`（帧 9～24）：**第一扫（右→中→左）**：发力干脆利落，扫帚贴地扫过中线直达左侧（跨边跳变处加入 `skip_cross` 跳过光流防拉丝）；末端刹停，发尾与猫尾顺惯性轻扬回落。
  - `4.4s～7.0s`（帧 25～38）：**第二扫（左→中→右）**：反手借力经中线利落挥向右前方；末端刹停回落，随后直起腰身竖握扫帚。
  - `7.0s～8.8s`（帧 39～48）：左手抬起轻擦额头露出一抹满足甜笑，扫帚化作星光消散，双臂垂落恢复标准站立。
- **粒子描写**：刷毛后方生成离散暖金/亮粉/青白细碎星尘与程序化深紫描边四芒星（脚本剥离所有暖暗棕星云黑带）；擦汗时头顶闪过 `2` 颗亮白清爽星芒，首尾 3 帧包络归零。
- **配速建议**：挥扫发力 `125ms`，两端刹停回落 `175ms`，起势与擦汗收尾 `220ms`。

#### 03. 专注写代码·戴摘眼镜版 👓（`03coding` | 9.3s | 48 帧 `8×6` | 循环）

```python
import os
import math
import shutil
from collections import deque
import numpy as np
from PIL import Image
from scipy.ndimage import binary_dilation, binary_erosion, gaussian_filter

# 标准工程常量（严格对齐 AI_ANIMATION_PIPELINE_GUIDE.md）
CANVAS_SIZE = 384
TARGET_H = 306          # 纯站立/转身主体锁死高度（304~308px）
GROUND_Y = 366          # 脚底统一锚定 Y 坐标
OUTLINE_RGB = np.array([68.0, 48.0, 98.0], dtype=np.float32)  # 标准深紫描边色


# =========================================================
# 1. 逐列智能黑隙切分（严禁 w//4, h//3 均分，防切靴底与粒子串行）
# =========================================================
def find_cell_boxes(sheet_rgba: Image.Image, cols: int = 4, rows: int = 3):
    arr = np.array(sheet_rgba.convert("RGB"), dtype=np.uint8)
    h, w, _ = arr.shape
    max_rgb = arr.max(axis=2)
    bg_p95 = float(np.percentile(max_rgb[:12, :], 95))
    thresh = max(22, int(bg_p95 + 14))
    fg = max_rgb > thresh

    # 1) 按列能量谷底切出 4 列
    col_energy = fg.mean(axis=0)
    col_bounds = [0]
    for c in range(1, cols):
        center = int(w * c / cols)
        lo, hi = max(0, center - w // 12), min(w, center + w // 12)
        split_x = lo + int(np.argmin(col_energy[lo:hi]))
        col_bounds.append(split_x)
    col_bounds.append(w)

    # 2) 每列内部独立扫描行能量，优先取上方靴底之下的最上方零能量黑隙带
    boxes_grid = [[None] * cols for _ in range(rows)]
    for c in range(cols):
        x0, x1 = col_bounds[c], col_bounds[c + 1]
        row_energy = fg[:, x0:x1].mean(axis=1)
        row_bounds = [0]
        for r in range(1, rows):
            center = int(h * r / rows)
            lo, hi = max(0, center - h // 10), min(h, center + h // 10)
            zero_ys = np.where(row_energy[lo:hi] < 0.002)[0]
            if len(zero_ys) > 0:
                split_y = lo + int(zero_ys[0])  # 取最上方黑隙，把头顶粒子留给下一行
            else:
                split_y = lo + int(np.argmin(row_energy[lo:hi]))
            row_bounds.append(split_y)
        row_bounds.append(h)
        for r in range(rows):
            boxes_grid[r][c] = (x0, row_bounds[r], x1, row_bounds[r + 1])

    return [boxes_grid[r][c] for r in range(rows) for c in range(cols)]


# =========================================================
# 2. 绝对色度双层抠图 + 粒子反预乘 + 深紫边界去污 + 高斯抗锯齿
# =========================================================
def clean_matte_and_aa(img_rgba: Image.Image, bg_thresh: int = 24,
                       chroma_thresh: int = 14, glow_cutoff: int = 28) -> Image.Image:
    arr = np.array(img_rgba.convert("RGBA"), dtype=np.uint8)
    h, w, _ = arr.shape
    rgb = arr[:, :, :3].astype(np.int16)
    max_rgb = rgb.max(axis=2)
    min_rgb = rgb.min(axis=2)
    chroma = max_rgb - min_rgb

    # 绝对色度判别纯黑背景（保护深紫衣靴）
    is_black = (max_rgb <= bg_thresh) & (chroma <= chroma_thresh)
    visited = np.zeros((h, w), dtype=bool)
    bg_mask = np.zeros((h, w), dtype=bool)
    q = deque()

    for x in range(w):
        for y in (0, h - 1):
            if is_black[y, x] and not visited[y, x]:
                visited[y, x] = True; q.append((y, x))
    for y in range(h):
        for x in (0, w - 1):
            if is_black[y, x] and not visited[y, x]:
                visited[y, x] = True; q.append((y, x))

    while q:
        cy, cx = q.popleft()
        bg_mask[cy, cx] = True
        for ny, nx in ((cy - 1, cx), (cy + 1, cx), (cy, cx - 1), (cy, cx + 1)):
            if 0 <= ny < h and 0 <= nx < w and not visited[ny, nx] and is_black[ny, nx]:
                visited[ny, nx] = True
                q.append((ny, nx))

    # 清理腿间/尾弯封闭纯黑空隙
    bg_mask |= (max_rgb <= max(18, bg_thresh - 4)) & (chroma <= chroma_thresh) & (~bg_mask)
    fg_mask = ~bg_mask

    # 识别主连通域（角色本体）
    comp_id = np.zeros((h, w), dtype=np.int32)
    cur_id, best_id, best_area = 0, 0, 0
    for y in range(h):
        for x in range(w):
            if fg_mask[y, x] and comp_id[y, x] == 0:
                cur_id += 1
                area = 0
                cq = deque([(y, x)])
                comp_id[y, x] = cur_id
                while cq:
                    py, px = cq.popleft()
                    area += 1
                    for ny, nx in ((py - 1, px), (py + 1, px), (py, px - 1), (py, px + 1)):
                        if 0 <= ny < h and 0 <= nx < w and fg_mask[ny, nx] and comp_id[ny, nx] == 0:
                            comp_id[ny, nx] = cur_id
                            cq.append((ny, nx))
                if area > best_area:
                    best_area, best_id = area, cur_id

    out = arr.astype(np.float32)
    out[bg_mask] = 0.0

    # 独立发光粒子反预乘
    particle_mask = fg_mask & (comp_id != best_id)
    ys, xs = np.where(particle_mask)
    for y, x in zip(ys, xs):
        m = int(max_rgb[y, x])
        if m < glow_cutoff:
            out[y, x] = 0.0
        elif m < 220:
            scale = 255.0 / max(1, m)
            out[y, x, :3] = np.clip(out[y, x, :3] * scale, 0, 255)
            out[y, x, 3] = min(255.0, m * 1.15)

    # 外轮廓 1~2px 边界色彩去污（向标准深紫描边收敛）+ 高斯抗锯齿平滑
    main_mask = comp_id == best_id
    boundary = binary_dilation(main_mask, iterations=1) & (~binary_erosion(main_mask, iterations=2))
    dark_edge = boundary & (max_rgb < 110) & (out[:, :, 3] > 0)
    out[dark_edge, :3] = out[dark_edge, :3] * 0.45 + OUTLINE_RGB * 0.55

    smooth_a = gaussian_filter(out[:, :, 3], sigma=0.60)
    out[boundary, 3] = smooth_a[boundary]
    out[out[:, :, 3] < 10.0] = 0.0

    return Image.fromarray(np.clip(out, 0, 255).astype(np.uint8), "RGBA")

# 3. 主体身高锁死对齐（严禁用整格 BBox）+ 备份 + 双底色预览导出
# =========================================================
def align_by_main_body(frames_rgba, target_h=TARGET_H, ground_y=GROUND_Y, canvas_size=CANVAS_SIZE):
    aligned = []
    for img in frames_rgba:
        arr = np.array(img, dtype=np.uint8)
        alpha_mask = arr[:, :, 3] > 20
        if not alpha_mask.any():
            aligned.append(Image.new("RGBA", (canvas_size, canvas_size), (0, 0, 0, 0)))
            continue

        # 仅测最大连通域（角色主体）的高度与脚底
        h, w = alpha_mask.shape
        comp = np.zeros((h, w), dtype=np.int32)
        cid, best_id, best_area = 0, 0, 0
        for y in range(h):
            for x in range(w):
                if alpha_mask[y, x] and comp[y, x] == 0:
                    cid += 1
                    area = 0
                    q = deque([(y, x)])
                    comp[y, x] = cid
                    while q:
                        py, px = q.popleft()
                        area += 1
                        for ny, nx in ((py - 1, px), (py + 1, px), (py, px - 1), (py, px + 1)):
                            if 0 <= ny < h and 0 <= nx < w and alpha_mask[ny, nx] and comp[ny, nx] == 0:
                                comp[ny, nx] = cid; q.append((ny, nx))
                    if area > best_area:
                        best_area, best_id = area, cid

        by, bx = np.where(comp == best_id)
        body_y0, body_y1 = int(by.min()), int(by.max())
        body_h = max(1, body_y1 - body_y0 + 1)
        scale = target_h / body_h

        # 按主体头部（顶部 18%~42%）中位 X 对齐水平中心 192
        head_band = (by >= body_y0 + int(body_h * 0.18)) & (by <= body_y0 + int(body_h * 0.42))
        head_cx = float(np.median(bx[head_band])) if head_band.any() else float(np.median(bx))

        nw, nh = max(1, int(round(w * scale))), max(1, int(round(h * scale)))
        resized = img.resize((nw, nh), Image.Resampling.LANCZOS)
        paste_x = int(round(canvas_size / 2.0 - head_cx * scale))
        paste_y = int(round(ground_y - body_y1 * scale))

        canvas = Image.new("RGBA", (canvas_size, canvas_size), (0, 0, 0, 0))
        canvas.paste(resized, (paste_x, paste_y), resized)
        aligned.append(canvas)
    return aligned


def backup_if_exists(path, backup_dir="gemini/backup"):
    if os.path.exists(path):
        os.makedirs(backup_dir, exist_ok=True)
        shutil.copy2(path, os.path.join(backup_dir, os.path.basename(path)))


def export_standard_assets(code, short_name, cn_name, frames, durations, is_loop=True):
    os.makedirs("gemini/成品", exist_ok=True)
    os.makedirs("gemini/预览", exist_ok=True)

    n = len(frames)
    cols = 8 if n >= 40 else 6
    rows = math.ceil(n / cols)

    sheet = Image.new("RGBA", (cols * CANVAS_SIZE, rows * CANVAS_SIZE), (0, 0, 0, 0))
    for i, f in enumerate(frames):
        r, c = divmod(i, cols)
        sheet.paste(f, (c * CANVAS_SIZE, r * CANVAS_SIZE), f)

    anim_path = f"gemini/成品/{code}{short_name}（{cn_name}_动画）.webp"
    sheet_path = f"gemini/成品/{code}{short_name}_sheet（{cn_name}_图集）.webp"
    backup_if_exists(anim_path)
    backup_if_exists(sheet_path)

    sheet.save(sheet_path, format="WEBP", lossless=True, quality=100)
    frames[0].save(
        anim_path, format="WEBP", save_all=True, append_images=frames[1:],
        duration=durations, loop=0 if is_loop else 1,
        lossless=True, quality=100, disposal=2,
    )

    # 同步导出纯白 / 纯黑双底色质检预览图
    for bg_name, bg_rgb in (("white", (255, 255, 255, 255)), ("black", (0, 0, 0, 255))):
        bg = Image.new("RGBA", sheet.size, bg_rgb)
        bg.alpha_composite(sheet)
        bg.convert("RGB").save(f"gemini/预览/{code}{short_name}_{bg_name}.png")

    print(f"[完成] {code}{short_name}: {n}帧 ({cols}x{rows}) | 总时长 {sum(durations)/1000:.2f}s")
```
