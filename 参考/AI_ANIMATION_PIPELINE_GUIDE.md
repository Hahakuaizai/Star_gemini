# 桌宠高流畅动画制作与老图集精修工程指南（AI 接手必读）

> **文档定位**：本指南沉淀了本项目制作与精修 48 帧丝滑透明底 WebP 动画/精灵图集的完整工程方法，专门用于指导后续 AI：
>
> 1. **从零制作高流畅新动作**（少生图省额度 + 补足中间帧 + 丰富粒子 + 零裁切）；
> 2. **精修已有低质量动作**（彻底解决：缺失中间帧不流畅、大量重复水帧、描边模糊/锯齿毛刺、星云黑块残留、人物忽大忽小、动画速度太快）。

## 二、 从零制作超流畅 48 帧动画的标准方法

### 1. 省额度分段生图策略

- **每次生图严格只尝试 1 次**（Prompt 开头声明 `Make ONLY 1 generation attempt. Do NOT retry`），先用 `read_file` 目视核查再决定下一步，可节省 3 倍额度。
- **2 段 `4×3`（24 关键帧）→ 48 帧丝滑动画**：无需硬画 4 段，先以 `anchor_stand.png` 生第 1 段（12 格），用 `python gemini\脚本\build_webp.py extract-anchors` 提取第 1 格与第 12 格作接力参考图，再生第 2 段（12 格）。
- **防裁切构图锁**：Prompt 必须写明人物占单格高度约 **`68%～72%`**、四边留白 `≥12%`、**严禁写“Frame 13..24”字样**（改写 `Row 1 Col 1` 防止模型在左上角印出白色数字），并要求全 3 行保持纯黑底 `#000000`（无文字、无网格、无地面阴影）。

### 2. 逐列智能黑隙切分（防切靴底 / 防头顶粒子串行）

禁止使用死板的 `w // 4, h // 3` 均分切格！AI 排版常有行高微偏，均分极易切掉靴底或把下一行头顶的爱心/星星切进上一行脚底。

- **标准做法**：直接复用 `gemini/脚本/build_webp.py` 中的 `find_cell_boxes(sheet, cols=4, rows=3)`：
  1. 先按整图列能量谷底切出 4 列；
  2. 再在**每一列内部独立扫描行能量**，优先取紧贴上方角色靴底之下的**最上方零能量黑隙带**（从而把下方角色头顶的悬浮粒子完整保留给下方格子）。
- 若某张图背景偏灰或第 3 行出现色块污染，先测顶部边框 95 分位亮度 `bg = np.percentile(arr[:12].max(2), 95)`，动态设置阈值 `t = max(22, bg + 14)`；必要时仅裁取纯黑底的前 2 行（参考 `14process_drag_float.py` 的 `extract_pure_black_rows`）。

### 3. 三类动作的“加中间帧”核心方法（按动作类型选用）

#### 方法 A：常规肢体/表情/道具动作 → 双向金字塔光流 + 一致性门控插帧（主力方案）

**严禁使用帧间透明度叠化（Alpha Cross-fade）**，否则会产生明显双影与黑影。正确做法是**双向稠密光流像素形变**（已封装于 `expand_48.py`、`02process_sweeping.py`、`10process_happy_jump.py`）：

```python
# 核心流程（纯 NumPy + SciPy，直接复用 expand_48.py 中的 pyramidal_optical_flow & warp_rgba）：
# 1. 构建“亮度 + 轮廓权重”特征图，让赛璐璐描边也能被光流精准追踪
def feature_map(arr):
    al = arr[:, :, 3].astype(np.float32) / 255.0
    lum = (0.299 * arr[:, :, 0] + 0.587 * arr[:, :, 1] + 0.114 * arr[:, :, 2]) / 255.0
    return lum * al + 0.45 * al

# 2. 4层高斯金字塔计算前向流 F_AB 与后向流 F_BA（win_sigma=3.5, iters=6）
vx_ab, vy_ab = pyramidal_optical_flow(fa, fb, levels=4, win_sigma=3.5, iters=6)
vx_ba, vy_ba = pyramidal_optical_flow(fb, fa, levels=4, win_sigma=3.5, iters=6)

# 3. 预乘 Alpha 后做双向形变（防止暗底色渗出黑边）
wa = warp_rgba(a, -t * vx_ab, -t * vy_ab)
wb = warp_rgba(b, -(1.0 - t) * vx_ba, -(1.0 - t) * vy_ba)

# 4. 一致性门控融合：前后向一致处平滑混合，遮挡/眨眼/粒子突变处果断吸附清晰帧，杜绝双影！
disagree = np.abs(wa[:, :, :3] - wb[:, :, :3]).mean(axis=2) / 255.0 * 0.7 \
         + np.abs(wa[:, :, 3] - wb[:, :, 3]) / 255.0 * 0.9
agree_w = np.clip(1.0 - disagree * 2.6, 0.0, 1.0)
prefer_a = (wa[:, :, 3] >= wb[:, :, 3]).astype(np.float32)  # 或按 t <= 0.5 取更近帧
w_a = (1.0 - t) * agree_w + prefer_a * (1.0 - agree_w)

# 5. 柔和抗锯齿 Alpha 曲线 [28..228]（绝不用 >=128 硬二值化，消除锯齿毛刺！）
out_a_u8 = np.clip(out_a * 255.0, 0, 255)
out[:, :, 3] = np.where(out_a_u8 < 28, 0.0,
               np.where(out_a_u8 > 228, 255.0, (out_a_u8 - 28.0) / 200.0 * 255.0))
```

- **⚠️ 光流插帧避坑铁律**：
  - **跨边大跳变严禁硬插光流**：当猫尾、扫帚或手臂在相邻两帧间从画面左侧瞬间换到右侧时，光流会把道具/尾巴硬生生拉成“双头怪”或穿腿拉丝！**必须将该过渡加入 `skip_cross` 跳过插帧**，把多出来的帧额分配给同侧平滑过渡段（插 2 帧 `t = 1/3, 2/3`），参考 `02process_sweeping.py`。
  - **禁止对近似静止帧做 3 倍死板插帧**：如果相邻两关键帧本来几乎没动，插 3 帧只会制造“满屏重复水帧”的观感。

#### 方法 B：大角度转身 / 视角切换 → 专用手绘过渡桥接图（Bridge Sheet）

- 当动作包含正面 ↔ 侧身 75° 旋转（如 `13tsundere`），光流无法凭空画出新角度的五官与背面头发。
- **正确做法**：用 `turn_start.png`（正面）和 `turn_end.png`（侧身）作双参考图，专门生成 1 张 `4×3` 桥接图（如 `part_turns.jpg`）：第 1 行画 `18° → 36°（尾巴收到腿后）→ 54° → 68°` 侧转，第 2 行画 `60° → 42° → 22° → 5°` 回正，第 3 行画松手回落。将真实手绘角度帧接入序列后，仅在少数同侧大跨度处单步光流补帧。

#### 方法 C：规则物理轨迹动作 → 程序化几何变换 + 次级惯性滞后

- **钟摆晃动（如 `14drag_float`）**：不要让 AI 直接画歪斜身体（会导致忽大忽小与歪斜不均）。让 AI 只画**竖直悬挂**姿态 + 眨眼/踢脚，再由脚本：
  1. 先对竖直姿态做光流补帧；
  2. 对眼部以下区域施加 **90° 相位滞后 S 曲线剪切波**（`lag_px * smoothstep(y)`），使头部五官 100% 刚性不变形，而长发、裙摆、猫尾真实滞后飘动；
  3. 绕支点 `(192, 30)` 用预乘 `warp_rgba` 做 48 个互不重复的正弦旋转角 `θ_i = 15° · sin(2πi / 24)`；
  4. 程序化绘制带淡紫描边的亮白提拉线，确保白底黑底均清晰。
- **跳跃动作（如 `10happy_jump`）**：不要把起跳帧脚底钉死在地面！在腾空关键帧叠加平滑正弦抛物线抬升 `lift = max_lift * sin(πt)`（`max_lift ≈ 26~28px`），同时校验头顶粒子不碰顶边。

## 三、 精修老图集/低质量动画的五大核心修复术

当接手已有图集出现 **“不流畅、缺中间帧、重复帧多、边缘模糊有毛边、黑块脏晕、速度太快”** 时，按以下 5 步逐项根治：

### 修复 1：根治“描边不清晰、锯齿毛刺、黑边/白边”

- **病根排查**：检查旧脚本是否写了 `arr[:, :, 3] = np.where(arr[:, :, 3] >= 128, 255, 0)`！硬二值切边会把赛璐璐外描边的半透明抗锯齿像素一刀切碎，产生肉眼可见的锯齿毛刺；而直接阈值切黑底又会在外圈残留黑边。
- **根治四步法**（参考 `10process_happy_jump.py`、`11process_shock_v2.py`、`12process_shy.py`）：
  1. **四边泛洪去底 + 绝对色度内部黑洞清理**：用 `(max_rgb <= bg_thresh) & (chroma <= 14)` 清理外部黑底和腿间/尾弯黑洞，避免相对饱和度误伤深紫衣服。
  2. **悬浮发光粒子反预乘（Un-premultiply）**：对独立于主体外的星星、爱心、汗滴、音符、受惊白线，按亮度 `scale = 255 / max_rgb` 还原纯亮色 RGB 并平滑赋透明，彻底消除粒子黑晕；若白底可见度弱（如纯白受惊线/提拉线），衬一层 1~2px 柔和淡紫/深紫描边。
  3. **外轮廓 1~2px 边界色彩去污（Edge Color Decontamination）**：找出角色外轮廓 1~2px 边界带 `boundary = dilate(fg, 1) & ~erode(fg, 2)`，将混入黑底的暗边缘像素 RGB 向角色标准深紫描边色 **`(68, 48, 98)`** 平滑收敛融合。
  4. **边界 Alpha 高斯抗锯齿平滑**：仅在 `boundary` 边界带上对 Alpha 施加 **`gaussian_filter(alpha, sigma=0.55 ~ 0.65)`**，内部保持 `255` 实心、极低噪点 `< 10` 清零。白底无黑边、黑底无锯齿！

### 修复 2：根治“星尘/魔法特效周围的黑色/棕色星云脏块”

- **病根**：AI 在黑底上画星尘或发光弧线时，常附带一层半透明暗棕/暗紫晕染，且与角色主体粘连成同一连通域，普通粒子抠图无法触及，白底预览下变成难看的黑块或棕色弯月带。
- **根治组合拳**（参考 `02process_sweeping.py` 的 `remove_nebula_blobs_aligned` 与 `clean_nebula.py`）：
  1. **角色衣靴核心区保护**：在 `384×384` 对齐后，水手服上衣/百褶裙（`x∈[148,236], y∈[172,282]`）和双靴（`x∈[150,234], y∈[312,366]`）加入保护蒙版。
  2. **色相识别暖暗棕黑带**：角色所有深色衣靴描边均为冷紫色（`B > R + 8`），凡 `max_rgb < 118` 且 `R >= B - 4` 的暖暗棕区域 100% 是星尘黑带。
  3. **形态学腐蚀-生长剥离（Erode & Regrow）**：角色描边仅 1~3px 宽，星云是厚重团块。对暗色候选区做 `erode(k=2)`——细描边全部消失得以 100% 保护，星云内核存活，再在“非亮主体 1px 邻域”内膨胀回填并清零为透明，对剥离边缘做反预乘提亮。

### 修复 3：清理重复水帧 & 重排关键帧 + 精准光流补帧

- **剔除废帧与水帧**：先打开原始素材或旧预览图逐格核查，剔除：
  - 几乎无变化的重复停顿帧；
  - 出现左右镜像漂移、突然伸手、脚底带黑影的废帧；
  - 顺序错乱的帧（如 `13tsundere` Part 2 中提前回正的帧，直接在脚本索引列表中按物理时序重排）。
- **精准扩帧至 48 帧（`8×6`）**：
  - 保留 20～36 个互不重复的高质量关键帧，**首尾强制锁死为 `keyframes[0]` 标准站姿**；
  - 在动作幅度最大的过渡区间插入 1～2 帧双向光流中间帧（避开跨边大翻边），凑齐标准 **`8×6 = 48` 帧**（修正如旧版 `11poke_shock` 的 `18×2` 错误排版）。

### 修复 4：严格锁死人物大小、锚点与零裁切保护

- **严禁用整格 BBox 缩放**：头顶冒出爱心、感叹号、`?` 或小乌云时，整格 BBox 会突然拉高，直接导致角色本体“缩水”！
- **标准缩放锚定法**：
  - **纯站立/微动/原地转身动作**：只测角色主连通域（`get_main_component_mask`）身高，直接按 `scale = TARGET_H / body_h`（`TARGET_H = 304~308px`）锁定，脚底锚定 `GROUND_Y = 366`，头中心对齐 `x = 192`，实测全片高度波动可控制在 **±2px 内**。
  - **含下蹲/跳跃/踢脚动作**：仅用**站立/非踢脚帧**的中位数身高与头部宽度（主连通域顶部 `18%～42%` 行宽中位数）算基准缩放系数，下蹲/踢脚帧按基准系数微调（夹紧 `±3%`），保证下蹲时不放大、踢脚时不缩水。
  - **⚠️ 局部裁靴补全血泪教训**：若某段原图小腿以下微裁需要借用 `ref_stand` 补靴，**必须在接缝 `seam_y` 以下做全宽羽化拼接 `out[y, :, :] = (1-t)*c + t*ref`**，**严禁只拼双腿列并把左右清零**（否则会把右侧延伸到低处的猫尾拦腰斩断！）。

### 修复 5：解决“动画速度太快”——变速节奏公式

- 旧版 36 帧动作常只有 5～6 秒，观感急促像“抽搐”。精修扩展到 **48 帧** 后，总时长应落在 **`8.0s ～ 9.2s`**（单动作黄金区间 `6.0s ～ 10.0s` 偏舒展侧）：
  - **爆发/发力/挥扫/起跳下落帧**：`120ms ～ 145ms`（干脆利落不拖沓）
  - **常规推进/光流过渡帧**：`160ms ～ 185ms`（肉眼能清晰欣赏每个过渡细节）
  - **表情卡点/庆祝/眨眼/擦汗/首尾站姿**：`215ms ～ 250ms`（给足呼吸感与情绪停留）
- **丰富粒子增强（按需）**：若用户要求更多粒子（如 `02sweeping`），除反预乘增强原图星尘外，可在脚本中用 `ImageDraw` 叠加带深紫细描边 + 亮白核心的程序化四芒星，并乘以首尾 3 帧归零的平滑包络线（确保首尾站立绝对干净）。

### 补充实战技巧（动作 18～23 沉淀）

- **64 帧（`8×8`）超高流畅多步光流扩展（参考 `22process_eat_cookie.py` 的 `interpolate_flow_multi`）**：21～23 个关键帧扩成 48 帧仅每区间插 1 帧，扩成 **64 帧（`8×8`）** 时只需算一次双向光流 `(vx_ab, vy_ab, vx_ba, vy_ba)`，即可在同一区间按 `ts=[1/3, 2/3]`（或跨度较大处 `[0.25, 0.5, 0.75]`）连续合成 2～3 帧丝滑过渡，配合 `110ms / 135ms / 185ms` 变速帧表保持总时长 `8.5～9.0s`。
- **暗灰绿渐变底大图防切格串行（参考 `23process_magic_flower.py` 的 `clean_sheet_for_split`）**：当生图原图背景不是纯黑而是暗灰绿渐变时，直接调用 `find_cell_boxes` 会因阈值误判导致跨行切错（把上一行靴底切进下一行头顶）。必须先按每行左右 12px 边缘中位色做 `clean_sheet_for_split` 置黑预处理，再用 `find_cell_boxes` 切格并回原图抠像。
- **局部缺件最小代价补修（参考 `18process_note_taking.py`）**：若某一段中仅有少数几格漏画了眼镜或道具（如 18 号动作的 `p1[3..7]`），无需重做整套动作——单独生成 1 张修正图 `part1_glasses_fix.jpg`，在脚本里仅对缺件索引替换为修正图对应格，其余格保持原样，即可零画风漂移修复。
- **半透明淡出道具防灰晕（参考 `20process_thread_needle.py` 的 `fix_fading_moons`）**：AI 在黑底上直接画“逐渐淡出”的暖黄月亮或光球时，低亮度区域经反预乘后在白底预览下极易发灰发脏。正确做法是从最清晰帧裁取该道具模板，清零淡出帧的对应区域后，直接按透明系数（如 `0.62 → 0.34 → 0.14`）叠加清晰模板，白底黑底均纯净无灰晕。
- **单格镜像废帧剔除补齐（参考 `20process_thread_needle.py`）**：若单格出现猫尾跳左侧/异色瞳反转等不可逆镜像错误（如 `p1[3]`），直接剔除该帧，并在相邻平缓过渡段多分配 1 处双步光流（`t = 1/3, 2/3`）补足帧数，比强行保留废帧更自然。
